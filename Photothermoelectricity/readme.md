
# Arduino-codes-Photothermoelectricity (This is the closest I could find to combining light, display, temperature, and motor; which I did for fun :D)

## This is some code I made, you can use it.

### There's a very big setup, but it has a LCD, two (blue and red) leds, a temperature and humidity sensor, and a microservo motor. The LCD will display the temperature that the sensor senses (in Fahrenheit). When the temperature is more than 73 degrees, the red LED and the servo motor will turn on, when it is less than 73 degrees, both the LED and motor will turn off, but the blue LED will turn on.
