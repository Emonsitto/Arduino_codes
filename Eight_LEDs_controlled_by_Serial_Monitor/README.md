
# Arduino-codes-Eight_LEDs_controlled_by_Serial_Monitor

## This is some code I made, you can use it.

### There are eight LEDs (Red, Blue, Yellow, and Green) on a breadboard connected to a 74HC595 Shift Register, and you can control it from the serial monitor!!!1!!1! (You can Toggle LEDs one by one, turn them all on, and/or turn them all off)
