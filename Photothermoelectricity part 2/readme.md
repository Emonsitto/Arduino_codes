
# Arduino-codes-Photothermoelectricity part 2

## This is some code I made, you can use it.

### There's a very big setup, but it has a LCD, two (blue and red) leds, a temperature and humidity sensor, and a microservo motor. The LCD will display the temperature that the sensor senses (in Fahrenheit). You can also set the "Ideal Temperature" or "Wished Temperature" by pressing two numbers in the IR Remote to form a 2-digit number.  When the temperature is more than the ideal temperature, the red LED and the servo motor will turn on, when it is less, both the LED and motor will turn off, but the blue LED will turn on, and when it is the same, everything will turn off.
