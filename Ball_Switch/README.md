
# Arduino-codes-LED_Switch

## This is some code I made, you can use it.

### There is a ball switch or tilt ball switch that turns on the built-in LED from the Arduino when it is looking up. This happens because of an internal switch that opens and closes depending on the angle it is at, this is also explained in the video which you can watch from the link below.
