
# Arduino-codes-Eight_LEDs_w_Shift_Register

## This is some code I made, you can use it.

### There are eight LEDs (Red, Blue, Yellow, and Green) on a breadboard and with the help of a 74HC595 Shift Register, they get turned on one by one. It's pretty :)
