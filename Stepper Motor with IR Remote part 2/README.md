
# Arduino-codes-Stepper Motor with IR Remote

## This is some code I made, you can use it.

### The setup is exactly the same as [Stepper Motor with IR Remote](https://github.com/Emonsitto/Arduino_codes/tree/main/Stepper%20Motor%20with%20IR%20Remote), but instead of pressing a button to move the motor, you enter a 3-digit number (000-999) on the IR remote. After the third digit is entered, the stepper motor rotates that exact number of steps. You can also change the motor speed with the Up and Down buttons, enable or disable input with the Power button, reset everything with St/Rept, and put the Arduino into sleep mode using Func/Stop.
