
# Arduino-codes-Stepper Motor with IR Remote

## This is some code I made, you can use it.

### There is a breadboard with a setup similar to [Stepper Motor](https://github.com/Emonsitto/Arduino_codes/tree/main/Stepper%20Motor), but there is also an IR reciever and Remote. The VOL- and VOL+ buttons make it spin.
