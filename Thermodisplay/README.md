
# Arduino-codes-Thermodisplay

## This is some code I made, you can use it.

### There is a thermistor and a Liquid Crystal display, with a pretty similar setup to "Blinking_SubscribeLCD." But this time, the temperature (In Celsius, Fahrenheit, and Kelvin) will be displayed.
