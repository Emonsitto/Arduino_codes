# Arduino-codes-LED&Buzzer_triggered_by_Thumb_Joystick (LnBtbTJ)

## This is some code I made, you can use it.

### There's a thumb joystick, a red LED, a blue LED, and an active buzzer. When the joystick is moved around, the intensity of the lights will change (X and Y values in the joystick are added, then divided by 8); when it is pressed, the buzzer will beep.
